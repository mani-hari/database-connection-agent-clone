   If VPCs differ: Run gcloud sql instances patch to fix
   If no Private IP: Use Cloud SQL Auth Proxy

5. Display connection summary with Host, Port, Method
   Generate connection code for the database type
   Test with: gcloud compute ssh {VM} --command="pg_isready -h {HOST} -p {PORT}"
